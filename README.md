# Library Manager

A simple command-line library management app written in Python.

## Features
- Add, list, search, and delete books
- Borrow and return books with due dates (14 days)
- Show overdue books
- Manage library members
- Data saved in JSON files

## How to run
1. Install Python 3
2. Clone this repository
3. Run: `python library.py`

## Project structure
- `library.py`: the main program
- `books.json` and `members.json`: created automatically on first run
